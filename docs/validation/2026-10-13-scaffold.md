# 工程骨架验证（2026-10-13）

环境：macOS arm64；Go 1.27.2；Node 24.15.0；npm 11.12.1；Wails 2.16.0。

- `go test ./internal/... ./cmd/...` 通过：缺失工具、正常版本输出、空输出、命令失败及 stderr 保留；HTTP 健康检查和错误路由。
- `npm --prefix admin test` 通过：健康协议校验、JSON 与非 JSON HTTP 错误。
- 两个前端 TypeScript 检查和 Vite 构建通过；`make build` 成功打包 macOS 应用。
- 启动 Go 服务并请求 `/healthz`，收到 `{"status":"ok","service":"qingfan-server"}`。
- `go test ./...` 的真实媒体集成检查失败：本机 Homebrew FFmpeg 8.1 和 ffprobe 均缺失 `libx265.215.dylib`，进程启动时 abort。未修改机器的 Homebrew 安装，需修复 FFmpeg 与 x265 的依赖匹配后重跑 `make doctor`、`make test`。
- 后台构建存在 Ant Design `use client` 指令和包体积提示；macOS 链接存在目标版本提示。构建成功，不据此承诺旧版 macOS 兼容。
